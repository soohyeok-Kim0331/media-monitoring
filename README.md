# 미디어 모니터링 자동화 사이트

매일 자동으로 뉴스를 모으고, Claude가 카테고리별로 3~4개씩 선별해서
웹사이트에 올려주는 시스템입니다.

- ESG 공통 / 환경 / 노동·인권 / 반부패·거버넌스 / 성평등·다양성 / 지속가능금융 / 정의로운 전환
  7개 카테고리, 카테고리당 3~4건씩 자동 게시
- 매일 정해진 시간(기본 KST 08:00)에 자동 실행
- 팀원들은 URL 하나만 열면 오늘의 기사 목록 확인 가능
- **사이트에서 부적절한 기사를 `↻`로 교체**할 수 있고, 이유를 적으면 앞으로도 비슷한 기사를 자동으로 걸러냄(아래 5번)
- 기사 표시 형식: `기사제목 (신문사, 260506)` — 제목에 원문 링크. 하단 **리스트 복사** 버튼으로 전체 목록 복사

뉴스는 두 갈래로 모읍니다.
1. **신뢰 언론사 RSS**(1차) — ESG경제·임팩트온·비즈니스포스트·연합뉴스 등 9개 매체의 기사를 직접 가져옵니다.
   원문 링크와 본문 요약이 함께 와서 선별 품질이 높습니다.
2. **Google News**(2차) — RSS를 제공하지 않는 매체(조선비즈·머니투데이·헤럴드경제·파이낸셜뉴스·뉴시스)와
   시의성 있는 기사를 보완합니다.

**비용**: 뉴스 수집(RSS + Google News), 호스팅(GitHub Pages), 자동 실행(GitHub Actions)은 모두 무료입니다.
기사 선별에 쓰는 Claude API만 사용량만큼 과금되며, 하루 7개 카테고리 기준으로 매우 적습니다(월 몇 천 원 수준).

---

## 준비물

1. **GitHub 계정** — https://github.com/join (무료)
2. **Anthropic API 키** (기사 선별용) — https://console.anthropic.com 에서 발급
   - 발급 후 결제수단 등록 + 소액 크레딧 충전 필요(사용량 기반 과금)

뉴스 수집에는 **API 키도, 별도 가입도 필요 없습니다.** 준비할 키는 Anthropic 것 **하나뿐**입니다.

## 설정 단계

### 1) 저장소 만들기
1. GitHub 로그인 → 우측 상단 `+` → `New repository`
2. 이름 예: `media-monitoring` → **Public** 선택 → `Create repository`
   (무료로 GitHub Pages를 쓰려면 공개 저장소여야 합니다)
3. 이 폴더의 모든 파일을 그대로 업로드
   - `Add file` → `Upload files` → 폴더 통째로 드래그 앤 드롭
   - `.github/workflows/daily.yml` 같은 숨김 폴더도 포함되어야 합니다
     (드래그가 안 되면 GitHub Desktop 앱 추천)

### 2) 비밀 키 등록 (Secrets)
저장소 → `Settings` → `Secrets and variables` → `Actions` → `New repository secret`
아래 **1개**만 등록:

| Name | Value |
|---|---|
| `ANTHROPIC_API_KEY` | Anthropic 콘솔에서 발급받은 API 키 |

### 3) GitHub Pages 켜기
저장소 → `Settings` → `Pages`
- `Source`: `Deploy from a branch`
- `Branch`: `main` / 폴더: `/docs` → `Save`
- 몇 분 후 `https://[계정명].github.io/media-monitoring/` 주소 생성 → 팀에 공유

### 4) 첫 실행
저장소 → `Actions` 탭 → `Daily Media Monitoring` → `Run workflow` 버튼
→ 2~4분 뒤 완료되면 Pages 주소 새로고침

이후 매일 자동으로(KST 08:00) 실행됩니다.

---

## 5) 부적절한 기사 교체하기 (재검색 + 기준 학습)

사이트에서 마음에 안 드는 기사를 **다른 기사로 교체**하는 기능입니다.
교체할 때 이유를 적으면, **앞으로도 비슷한 기사를 자동으로 걸러냅니다.**

1. 사이트에서 기사 왼쪽 **`↻`** 버튼을 누르면 그 기사가 교체 대상으로 표시됩니다.
   - 뜨는 입력란에 **부적절한 이유**를 적어주세요 (예: `지자체 행사 기사 제외`, `단순 실적 홍보성 기사 제외`).
     비워도 되지만, 적으면 앞으로 비슷한 기사가 걸러집니다.
2. 하단 **`재검색 목록 복사`** 버튼 → 창에서 **`복사`**
3. 저장소 → `Actions` → `Daily Media Monitoring` → `Run workflow`
   → **`refine`** 입력란에 붙여넣고 `Run workflow`
4. 2~4분 뒤 사이트가 갱신됩니다.
   - `↻` 표시 안 한 기사는 **그대로 유지**
   - `↻` 표시한 기사는 **다른 기사로 교체**되고 **영구 제외**(다시 안 나옴)
   - 적어둔 이유는 `data/criteria.json`에 카테고리별로 쌓여, **매일 실행 때마다 선별 기준에 반영**됩니다

> **리스트 복사** 버튼은 이와 별개로, 오늘 목록을 메일·메신저에 붙여넣을 텍스트로 복사합니다.
> `refine` 입력란을 비운 채 실행하면 평소처럼 새로 수집합니다.
> 학습된 기준을 초기화하려면 `data/criteria.json`을 `{}` 로 되돌리면 됩니다.

## 커스터마이징

- **키워드/언론사 수정**: `config.py`의 `CATEGORIES` 딕셔너리만 수정하면 됩니다.
  언론사를 새로 추가할 때는 `PRESS_DOMAINS`에 `"언론사명": "도메인"`도 함께 넣어주세요(우선 검색됨).
- **RSS 매체 추가**: `config.py`의 `PRESS_RSS`에 `"언론사명": "전체기사 RSS URL"`을 넣으면 1차 소스로 직접 읽습니다.
  대부분 `사이트주소/rss/allArticle.xml` 형태입니다. 섹션별(S1N*) 피드는 다른 매체 기사가 섞여 나오는
  사례가 있어 '전체기사' 피드만 쓰세요.
- **실행 시간 변경**: `daily.yml`의 `cron: "0 23 * * *"` (UTC 기준, KST = UTC+9)
- **선별 개수 변경**: `config.py`의 `SELECT_MIN`, `SELECT_MAX`
- **최신성 기준 변경**: `config.py`의 `MAX_ARTICLE_AGE_DAYS`
- **평일만 실행**: cron을 `"0 23 * * 0-4"`로 변경

## 알아두실 점 (한계)

- 신뢰 언론사 RSS(1차)는 원문 링크·요약이 확실해 품질이 높지만 RSS 제공 매체가 9곳뿐이라
  나머지는 구글 뉴스(2차)로 채웁니다. 구글 뉴스는 지자체 행사·업무협약 같은 지엽적 기사가 섞여
  들어오는데, ① 검색어가 제목/요약에 실제로 있는지 ② 신뢰 언론사인지 ③ 지자체 홍보/사진 스텁이
  아닌지로 순위를 매기고 ④ Claude가 최종 판단하는 다층 구조로 거릅니다. 그래도 완벽하지 않으니
  운영 초기 1~2주는 사람이 한 번씩 검수하시길 권장합니다(그럴 때 위 5번 재선별 기능을 쓰세요).
- 기사 링크는 구글 뉴스의 인코딩 주소를 원문 주소로 복원해 넣습니다. 구글이 방식을 바꾸면 간혹
  `news.google.com/...` 형태 링크가 그대로 나올 수 있는데, 그 링크도 클릭하면 원문으로 이동합니다.
  (RSS로 온 1차 기사는 처음부터 원문 링크라 이 문제가 없습니다.)
- 로컬(내 PC)에서 미리 돌려보려면 `python check_key.py`로 키 상태를 확인한 뒤 `python crawl_and_select.py`.
  Anthropic 키가 없고 로컬에 Claude Code CLI가 로그인돼 있으면 그걸로 대신 선별합니다(로컬 확인용).

## 문제 해결

- **Actions가 빨간색(실패)**: `Actions` 탭 → 실패한 실행 → 로그 확인. 대부분 `ANTHROPIC_API_KEY`
  미등록·오타이거나 크레딧 부족입니다.
- **사이트에 기사가 안 뜸**: `data/latest.json`을 열어 그날 어떤 카테고리가 비어있는지 확인하세요.
- **재선별했는데 안 바뀜**: `refine` 입력란에 붙여넣은 JSON이 사이트 `재선별 목록 복사`에서 받은
  그대로인지 확인하세요. 체크를 하나도 안 하면 전부 교체됩니다.
